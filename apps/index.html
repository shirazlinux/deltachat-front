WebXDC security & privacy notes

Please read these points before installing apps:

  • Code execution: WebXDC files run code on your device (sandboxed). Only open apps from trusted sources such as this store.
  • Internet access: Some apps may use the network (e.g. news). That can expose your IP to remote servers or chat peers.
  • Unknown senders: Never open .xdc files from strangers unless you fully trust the sender.

These apps are written by free software community developers; this chat server only hosts them.
